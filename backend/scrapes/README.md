# Scraper Test Files

Please paste the full HTML source code of the profile pages into the corresponding files:

- **instagram_profile.html**: Go to an Instagram profile (e.g. `instagram.com/hormozi`), scroll down to load some posts, then Right Click -> Save As -> "Webpage, Complete" or "HTML Only". Copy the content here.
- **tiktok_profile.html**: Go to a TikTok profile (e.g. `tiktok.com/@hormozi`), scroll to load videos, inspect element on the `body` tag, copy outer HTML, and paste here.
- **youtube_shorts.html**: Go to a YouTube channel's **Shorts** tab (e.g. `youtube.com/@AlexHormozi/shorts`), scroll down, and save the HTML.

The scraper will be configured to read these files to test the selectors without triggering bot detection.
